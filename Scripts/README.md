# Chicago Yard Mimicry Project Scripts

This folder contains the data wrangling, analyses, and visualizations used to evaluate spatial mimicry patterns among residential yards in Chicago.

## Folder Organization

### MantelGlobal

Global Mantel analyses used to evaluate relationships between yard similarity and spatial distance.

### MantelLocal

Local Mantel analyses used to identify localized spatial relationships among neighboring yards.

### MoransGlobal

Global Moran's I analyses used to evaluate overall spatial autocorrelation patterns across neighborhoods.

### MoransLocal

Local Moran's I analyses used to identify spatial clusters and neighborhood-level autocorrelation patterns.

## Contents

Scripts include:

* Data wrangling and preprocessing
* Statistical analyses
* Spatial autocorrelation analyses
* Visualization and graph generation
* Model output processing

## Software

* R
* Spatial Statistics
* Moran's I
* Mantel Tests
* Linux-based computing workflows
* Agent-Based Modeling outputs

These scripts support the analyses presented in the Spatial Mimicry and Front Yard Management in Chicago research project.
